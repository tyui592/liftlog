# 분석 탭 개선 계획

사용자 요청: 다른 운동 앱을 조사하고 유용한 분석 탭으로 직접 개선. 구성과 구현은 위임받음.

## 설계

- 기존 단일 `src/app.html`, 저장 형식, 운동 ID, 클라우드 동기화를 유지한다.
- 최근 7일 / 4주(기본) / 12주 / 전체 기간을 공통 기준으로 사용한다. 오늘까지의 완료된 유효 본세트만 집계하고 미래·웜업·빈 세트는 제외한다.
- 운동일·본세트·무게 볼륨·기록된 운동 시간을 같은 길이의 직전 기간과 비교한다. 이전 값이 0이면 가짜 증가율을 만들지 않는다. 시간 미기록은 0분으로 취급하지 않는다.
- 주간 운동량 지표를 전환하고, 부위별 본세트 수와 마지막 수행일을 보여준다. 운동량을 피로도나 권장 훈련량으로 해석하지 않는다.
- 기록한 종목을 검색·선택하고 지표 하나씩 차트에 표시한다. weight는 무게/추정 1RM/볼륨, reps는 최고/총 횟수, time은 총 시간. 최근 기록에서 해당 날짜로 이동한다.
- 같은 날 같은 종목을 여러 번 추가한 기록도 합산한다. 진행 중·미완료 운동도 체크한 유효 본세트만 반영한다.
- 새 라이브러리 없이 기존 테마 토큰과 인라인 SVG를 사용한다.
