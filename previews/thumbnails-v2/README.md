# 원본 벡터 비교 v2

`index.html`은 현재 / Workout Guide / Everkinetic 원본 중심 후보를 실제 52·40·32px, 라이트·다크 모드로 비교합니다. v1은 ../thumbnails/index.html에 보존했습니다. 프로덕션 변경 없음.

## 대응 판단

- 스쿼트: Everkinetic0122 바벨 스쿼트
- 레터럴 레이즈:0018 덤벨 레터럴 레이즈
- 바벨 컬:0211 일반 바벨 컬 (정확한 신규 확보; EZ바와 구분)
- 벤치 프레스:0042. 운동 설명은 바벨·벤치이나 그림은 벤치를 생략합니다. 해결했다고 간주하지 않습니다.
- 랫풀다운:0093 언더핸드 변형. 일반 종목의 변형 후보이지 와이드 오버핸드 정확 대응이 아닙니다.0097 와이드그립은 원본 SVG·PNG 모두 없습니다.
- 플랭크: 기존 Workout Guide 프레임1 유지. Everkinetic 표준 플랭크 원본은 확보하지 못했습니다.

권고: 원본 벡터를 주 자료로 검토하면 재트레이싱 차이를 줄이고 일반 바벨 컬 누락을 해결할 수 있습니다. 다만 벤치와 그립처럼 운동 인지에 중요한 문제는 자료만으로 해결되지 않았으므로120종 전면 교체는 아직 부적절합니다. 벤치 사진은 정확도 참고이며 일러스트로 오인하지 않도록 분리했습니다.

## 출처와 변경

Everkinetic https://github.com/everkinetic/data commit446bb9a3d0c3beb6b84f7c9d77dfc8af707a2ab6. 원본5장은 original/에 보존했습니다. assets/는 배경 흰색 그룹만 제거한 CC BY-SA4.0 변형입니다. CSS는 테마에 맞게 색과 크기를 조절하며 기구·자세는 바꾸지 않습니다. 각 원본 운동 메타데이터와 원본 URL에 대응하는 ID는 mapping.json에 보존했습니다. 라이선스 전문 LICENSE-ASSETS.md.

Workout Guide / Bryl Lim https://github.com/bryllim/workout-guide commit aac599224bb9780305239607ef98540b7e0ce389. 기존 비교본의 원본 파일과 source-manifest.json 및 출처·라이선스 고지 참조. 플랭크와 중간 비교열 그림도 CC BY-SA4.0입니다.

사진은 기존 assets/ex/ex010-0/1.webp의 복사본이며 free-exercise-db Unlicense 원본 매핑을 그대로 따릅니다. 이 화면의 기존 Liftlog 아이콘은 src/app.html에서 추출한 비교용 복사본입니다.

## 다음 작업의 우선순위

1. 원본 벡터를 유일한 주 자료로 바로 확정하지 않습니다. 일반 바벨 컬 누락은 해결했지만, 작은 썸네일의 복잡도와 벤치 생략·그립 차이를 모두 해결하지 못했기 때문입니다.
2. 사용자에게 원본 중심 후보의 선명도·인물 비율을 확인받고, 선택된 스타일에서 벤치 포함 그림과 와이드그립 그림을 추가 확보하거나 정확한 별도 제작을 진행합니다. 임의의 기구 도형을 덧붙여 자세 정확도가 검증된 것으로 보이게 하지 않습니다.
3. 승인된6종의 표현 규칙을 확정한 뒤120종 대응표를 실제 검토합니다. 이번 단계에서는120종의 정확 대응률을 측정하지 않았으며 임의 수치를 제공하지 않습니다.
4. RepDB는 공개 저장소에 자료 복사·파생 그림 제작을 위한 후보로 채택하지 않았습니다. WorkoutLabs도 서면 이용 권한 없이 포함하지 않았습니다.

### 축소 표시 대비 보완

원본 선이 작은 화면에서 희미해지는 점을 확인해 원본 후보의 썸네일에 테마 전경색을 명시하고0.45px 비확대 윤곽선을 추가했습니다. 원본 파일 및 자세·기구 경로는 유지하며 표시용 CSS에서만 처리합니다. 확대 보기에는 선 보강을 적용하지 않습니다.
